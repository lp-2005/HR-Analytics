📊 HR Analytics Dashboard | Power BI

📌 Project Overview

This project presents an interactive HR Analytics Dashboard built in Power BI to help analyze workforce data and identify key factors affecting employee attrition. The dashboard enables HR teams to monitor important metrics, understand employee trends, and support data-driven decision-making.

🎯 Objectives

- Analyze employee attrition trends.
- Monitor workforce demographics.
- Identify departments with higher attrition.
- Evaluate employee distribution by age, gender, education, and job role.
- Provide insights to support HR strategies.

🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel (Dataset)

📈 Key KPIs

- Total Employees
- Active Employees
- Attrition Count
- Attrition Rate
- Average Age
- Average Salary
- Average Years at Company

📊 Dashboard Features

- Employee Attrition Analysis
- Department-wise Employee Distribution
- Gender-wise Workforce Analysis
- Age Group Analysis
- Education Field Analysis
- Job Role Analysis
- Interactive Filters and Slicers

💡 Key Insights

- Identified departments with the highest employee attrition.
- Analyzed workforce distribution across different age groups and job roles.
- Compared employee demographics based on gender and education.
- Highlighted trends that can help improve employee retention.
